01 — ABOUT PROJECT

Automating the Software Delivery Process

The project demonstrates how DevOps tools can work together to create a repeatable and automated application delivery workflow.

01

Source Control

GitHub stores and manages the application source code while maintaining version history.

02

Continuous Integration

Jenkins automatically retrieves the source code and executes the configured pipeline stages.

03

Containerization

Docker packages the application into a portable and isolated container environment.

04

Web Deployment

Nginx serves the deployed application and provides access through the local web environment.
